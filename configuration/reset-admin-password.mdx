---
title: 'Reset admin password'
description: 'Recover access to the Rootprint admin account by clearing the admin users and the first-admin setup flag, then completing the setup wizard again.'
---

<Tip>
	If another admin can still sign in, you don't need this page. They can use **Settings → Users →
	Reset password** for you. See [Reset a password](/configuration/users#reset-a-password).
</Tip>

To recover a locked-out admin, delete every admin user and the first-admin setup flag from the database. Rootprint then reopens the setup wizard so you can create a new admin.

<Warning>
	Deleting a user also deletes everything it owns: sessions, linked accounts, API keys, saved views,
	shares, and preferences.
</Warning>

<Warning>
	While the setup flag is gone, anyone who can reach Rootprint can create the new admin. Before you
	delete it, allow only your own IP address at the reverse proxy or firewall. Keep that restriction
	until you have created the new admin.
</Warning>

## Delete the admins and the setup flag

Run both statements. The setup wizard at `/auth/setup-admin` stays closed while the `first_admin_claimed` row exists, even with no admin users left.

<CodeGroup>

```bash Docker Compose
docker compose exec db psql -U rootprint -d rootprint \
  -c "DELETE FROM \"user\" WHERE role = 'admin';"
docker compose exec db psql -U rootprint -d rootprint \
  -c "DELETE FROM app_settings WHERE key = 'first_admin_claimed';"
```

```bash External PostgreSQL
psql "$DATABASE_URL" -c "DELETE FROM \"user\" WHERE role = 'admin';"
psql "$DATABASE_URL" -c "DELETE FROM app_settings WHERE key = 'first_admin_claimed';"
```

</CodeGroup>

## Finish in the UI

Open your Rootprint URL (the `ORIGIN` value). Rootprint redirects you to `/auth/setup-admin`. Enter your admin credentials and submit the form. The new admin is active immediately, and you can reuse the old admin email.
