title: 'Send logs from Go'
description: 'Ship Go logs to Rootprint with the OpenTelemetry SDK and the slog bridge over OTLP HTTP.'

Send Go logs to Rootprint through the standard `slog` API, with the `otelslog` bridge and the OpenTelemetry `otlploghttp` exporter sending them over OTLP HTTP.

## Prerequisites

- A running Rootprint instance. Substitute its host for `<your-rootprint>`.
- Go 1.25+.
- An **ingest API key** scoped to an OpenTelemetry logs index such as `otel-logs-v0_9`. In **Settings → API keys**, click **Create ingest key** and pick the index. See [API keys](/api/overview).

## Setup

<Steps>
  <Step title="Create a module and install the OpenTelemetry packages">
    ```bash
    go mod init example.com/rootprint-demo
    ```

    ```bash
    go get go.opentelemetry.io/otel \
        go.opentelemetry.io/otel/log \
        go.opentelemetry.io/otel/sdk/log \
        go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp \
        go.opentelemetry.io/contrib/bridges/otelslog
    ```

  </Step>

  <Step title="Set environment variables">
    ```bash
    export OTEL_SERVICE_NAME=my-go-service
    export OTEL_EXPORTER_OTLP_LOGS_ENDPOINT='https://<your-rootprint>/v1/logs'
    export OTEL_EXPORTER_OTLP_LOGS_HEADERS='Authorization=Bearer%20<your-ingest-api-key>'
    ```

    <Warning>The `%20` after `Bearer` is required: OpenTelemetry SDKs expect URL-encoded values in `OTEL_EXPORTER_OTLP_LOGS_HEADERS`.</Warning>

  </Step>

  <Step title="Minimal working example">
    <Expandable title="main.go">
    ```go
    package main

    import (
        "context"

        "go.opentelemetry.io/contrib/bridges/otelslog"
        "go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp"
        "go.opentelemetry.io/otel/log/global"
        sdklog "go.opentelemetry.io/otel/sdk/log"
    )

    func main() {
        ctx := context.Background()
        exporter, err := otlploghttp.New(ctx)
        if err != nil {
            panic(err)
        }
        provider := sdklog.NewLoggerProvider(
            sdklog.WithProcessor(sdklog.NewBatchProcessor(exporter)),
        )
        defer provider.Shutdown(ctx)
        global.SetLoggerProvider(provider)

        logger := otelslog.NewLogger("hello")
        logger.InfoContext(ctx, "Hello from Go to Rootprint")
    }
    ```
    </Expandable>

    Log with `InfoContext`, `ErrorContext`, and the other `*Context` methods wherever a request context is in scope. A call without the context carries no span, so the log can't open its trace.

  </Step>

  <Step title="Verify in Rootprint">
    Open **Logs**, filter on `service_name:my-go-service`, and your record should appear within a few seconds.
  </Step>
</Steps>

## Structured logging

Pass key/value pairs through `slog`. The bridge turns them into log record attributes.

```go
logger.Info("user signed up",
    "user_id", "alice",
    "plan", "pro",
)
```

## Framework recipe: Gin

Set up the provider once at startup, then log from a middleware with the request's context.

<Expandable title="main.go — Gin">
```go
package main

import (
    "context"
    "log/slog"

    "github.com/gin-gonic/gin"
    "go.opentelemetry.io/contrib/bridges/otelslog"
    "go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp"
    "go.opentelemetry.io/otel/log/global"
    sdklog "go.opentelemetry.io/otel/sdk/log"
)

func initLogs(ctx context.Context) func() {
    exporter, err := otlploghttp.New(ctx)
    if err != nil {
        panic(err)
    }
    provider := sdklog.NewLoggerProvider(
        sdklog.WithProcessor(sdklog.NewBatchProcessor(exporter)),
    )
    global.SetLoggerProvider(provider)
    slog.SetDefault(otelslog.NewLogger("gin-app"))
    return func() { _ = provider.Shutdown(ctx) }
}

func main() {
    shutdown := initLogs(context.Background())
    defer shutdown()

    r := gin.New()
    r.Use(func(c *gin.Context) {
        slog.InfoContext(c.Request.Context(), "request", "method", c.Request.Method, "path", c.FullPath())
        c.Next()
    })
    r.GET("/", func(c *gin.Context) { c.JSON(200, gin.H{"ok": true}) })
    _ = r.Run(":3000")
}
```
</Expandable>

## Troubleshooting

- **401 or 403**: the ingest API key is missing or wrong, or the space after `Bearer` isn't written as `%20`. Check `OTEL_EXPORTER_OTLP_LOGS_HEADERS`. See [Response codes](/send-logs/otlp#response-codes).
- **`200` but no records in Logs**: the ingest API key is scoped to an index without the OpenTelemetry logs schema, so the records are discarded. See [Index target](/send-logs/otlp#index-target).
- **Nothing in Logs from a short-lived script**: the batch processor buffers records. Shut down the logger provider before exit, as the minimal example does.
- **TLS errors against a self-signed endpoint**: set `OTEL_EXPORTER_OTLP_CERTIFICATE=/path/to/ca.pem`.
