---
title: 'Send logs'
description: 'Pick the right ingestion path: OTLP for anything OpenTelemetry, the NDJSON gateway for custom-schema indexes.'
---

Rootprint accepts logs two ways:

- **OTLP HTTP**: OpenTelemetry logs over HTTP (protobuf). Use it with any OpenTelemetry SDK, the OpenTelemetry Collector, or a sidecar that speaks OTLP. OTLP logs must go to an OpenTelemetry logs index such as `otel-logs-v0_9` (see [Index target](/send-logs/otlp#index-target)).
- **NDJSON gateway**: an authenticated HTTP endpoint that ingests NDJSON. Use it when you control the wire format and write to a custom-schema index.

## Pick a path

| If you have…                                 | Use                                                                                      |
| -------------------------------------------- | ---------------------------------------------------------------------------------------- |
| An app in Python, Node.js, Go, or Zig        | The matching [language page](#languages) (OTLP SDK)                                      |
| Access logs from Caddy or Nginx              | The matching [web server page](#web-servers) (OpenTelemetry Collector or Vector)        |
| Container logs on a Linux host               | [Docker](/send-logs/platforms/docker) (Vector or OpenTelemetry Collector)                |
| Pods in a Kubernetes cluster                 | [Kubernetes](/send-logs/platforms/kubernetes) (OpenTelemetry Collector DaemonSet)        |
| Logs already on disk on a Linux host         | [OpenTelemetry Collector](/send-logs/log-agents/otel-collector), [Fluent Bit](/send-logs/log-agents/fluent-bit), or [Vector](/send-logs/log-agents/vector) |
| Existing pipeline that emits your own schema | [NDJSON gateway](/send-logs/http)                                                       |
| Syslog from Linux hosts or network appliances  | [Syslog](/send-logs/syslog) (rsyslog + Vector)                                       |
| An app in another language, or anything else that speaks OTLP | [OTLP reference](/send-logs/otlp)                                       |
| Spans to send, not logs                      | [Traces overview](/traces/overview)                                                     |
